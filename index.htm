Dashboard · Completed

Indonesia Inflation Monitoring & Analysis Dashboard

Question
How have Indonesia’s inflation trends evolved over time? Which inflation components contribute to price movements, and how do changes in the BI Rate relate to inflation trends?
Method
Developed an interactive, three-page dashboard using monthly Indonesian inflation and BI Rate data. The analysis involved data preparation, date table creation, data modeling, DAX measure development, and time-series visualization. The dashboard covers:
  • Inflation Overview: Tracks headline inflation (YoY, MtM, and YtD) and BI Rate trends.
  • Inflation Drivers: Compares Core Inflation, Volatile Food, and Administered Prices over time.
  • Monetary Policy Analysis: Explores the relationship between BI Rate movements and year-on-year inflation.

Featured · Undergraduate Thesis

Model Regresi Random Forest untuk Prediksi Land Surface Temperature di Kota Surabaya dengan Interpretasi Feature Importance

Can surface temperature in Surabaya be predicted from land, climate, and population variables, and which of them matter most?

01

Data

Landsat LST via Google Earth Engine, NASA POWER and BMKG climate data, plus demographic and spatial variables.

02

Preparation

Spatio-temporal data processing, preprocessing, and variable selection on a 600 m grid of Surabaya, using Python and KNIME.

03

Model

Random Forest regression, optimized and evaluated with Grid Search and 5-fold cross-validation.

04

Interpretation

Feature importance used to explain which factors drive temperature differences across the city.

4.3%MAPE
